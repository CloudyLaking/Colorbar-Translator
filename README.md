# Colorbar Translator v1.0.1

独立、离线优先的色条截图转换器。直接打开 `index.html`，或将此目录作为静态站点部署；不需要 Python、Node 服务或网络模型。Node 仅用于开发测试。

## 使用

载入或粘贴图片后自动寻找候选色条、识别连续／分段类型并生成代码。对照原图检查选区；必要时拖动框选。纵向默认从上往下读取，可反转。所有图片仅在本地浏览器处理。

支持 Matplotlib、Plotly、GMT CPT、CSS、JSON、JavaScript。连续色条保留不等距 RGB 控制点；分段色条保留不等宽色块与硬边界。导出前需确认数值范围与线性／对数尺度；不确认时只输出归一化配色。自定义数值边界须严格递增，数量为色块数加一。

## 能力边界

目标是尽可能一键处理常见矩形 colorbar，**不是保证任意截图都能精确还原**。拍照透视、旋转、弯曲、三角延伸端、多色条混杂、透明合成、严重压缩和缺失刻度仍需人工核对。当前不依赖旧版低可靠度的自动数字识别；数值刻度需用户确认。截图配色不等于原始高精度色表。

RGB 重建误差只衡量抽取后的采样曲线，不是感知色差，也不是检测选区正确率。连续对数色标导出至 Plotly/CPT 使用 1025 点近似。图像限制 30 MiB、2500 万像素。支持现代 Chrome、Edge、Firefox；不支持 Internet Explorer。

## 目录

- `index.html` / `style.css`：独立界面，不依赖网站源码。
- `src/core.js`：采样、分段、误差控制、统一模型和导出。
- `src/detect.js`：色条候选检测。
- `src/app.js`：图片读取、框选、预览、复制与下载。
- `tests/`：已知颜色及位置的回归测试。

运行 `npm test`。产品版本由 `src/core.js` 定义，测试核对发行版本。网站、MeteoStation Plotter 和本项目独立维护版本。
